# Active Directory Azure Homelab

## Overview

Built a Windows Server Active Directory lab in Microsoft Azure to develop infrastructure and PowerShell administration skills.

## Environment

- Microsoft Azure
- Windows Server
- Active Directory Domain Services
- PowerShell

## Tasks Completed

- Created Azure Virtual Machine
- Promoted server to Domain Controller
- Created Active Directory forest
- Created Active Directory domain (lab.local)
- Created Organisational Units (OUs)
- Created users
- Created security groups
- Added users to groups
- Used PowerShell AD cmdlets

## PowerShell Commands Used

Get-ADUser -Filter *
Get-ADDomain
Get-ADForest
Get-ADGroup
Get-ADGroupMember
